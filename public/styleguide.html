Color tokens

Use the CSS variable, never the raw hex, so per-campaign theming stays possible. --accent and --glow are the two meant to change per campaign — override them on :root or any wrapper.

The full warm gray ramp (--gray-100 … --gray-950), base status accents (--base-blue/green/red/yellow) and semantic aliases (--surface-*, --text-*, --border-*) are all defined in styles.css — these landing tokens map onto them. To theme a whole page to one persona, set --accent to a manager color, e.g. --accent:var(--mgr-social-bright).

Manager-color system

The signature device: each persona owns a color used as a tag and to tint cards. Chroma-normalized — only the hue changes. Each has a deep *-regular fill and a brighter *-bright accent. Theme any tag or card with data-mgr="ar|booking|creative|fan|marketing|opportunities|project|social".

Typography

Three families: --font-display Syne (headlines, labels, nav), --font-serif Newsreader italic (editorial leads, accents), --font-body Manrope (body, buttons). Syne + Newsreader are sized to read at the same visual scale when paired.
